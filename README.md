# شرائح

أداة محلية لتقسيم الصور إلى ٢–٢٠ شريحة طولية مع انحناء أطراف قابل للتعديل وفواصل قابلة للضبط. المعالجة والتصدير يعملان في المتصفح دون رفع الصور أو مكتبات خارجية.

## التشغيل
افتح index.html في متصفح حديث. على الجوال يفضل استخدام رابط GitHub Pages.

## GitHub Pages
1. ارفع index.html و .nojekyll إلى جذر مستودع GitHub.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر main ثم / (root) واضغط Save.

## الاستخدام
أرفق صورة JPG أو PNG أو WebP، وحدد عدد الشرائح وانحناء أطرافها والفاصل واتجاه الترقيم. اضغط الشريحة لعرضها وتحميلها وحدها، أو تحميل الشرائح ZIP لتصدير الجميع.

الملفات مرقمة 01.png حتى 20.png للحفاظ على ترتيبها. PNG يحفظ شفافية الأطراف. الفاصل يستبعد جزءًا من جانبي كل شريحة؛ صفر يحفظ كامل عرض الصورة. الانحناء موحد لجميع الشرائح. الصور التي تتجاوز 50 مليون بكسل لا تقبل لتقليل ضغط الذاكرة.

الموقع لا يزيل الفواصل أو الأطراف الموجودة في الصورة الأصلية تلقائيًا؛ استخدم الصورة الأصلية غير المقطعة لأفضل نتيجة.
